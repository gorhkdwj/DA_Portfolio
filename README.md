# 김재천 | 데이터 분석가(Data Analyst) 포트폴리오

안녕하세요. 데이터 분석 및 AI 포트폴리오에 오신 것을 환영합니다! 이 저장소는 데이터 분석, 머신러닝, 프로그래밍 분야에서의 역량과 꾸준한 성장을 보여주는 프로젝트, 실전 연습, 이론 학습 및 코딩 기록들을 모아둔 공간입니다.

---

## 🛠 기술 스택 및 역량 (Tech Stack & Skills)

- **Languages**: Python, SQL
- **Data Analytics / EDA**: Pandas, NumPy, Matplotlib, Seaborn, Scipy, Pingouin
- **Machine Learning**: Scikit-learn, Decision Trees, Classification Models
- **Tools / Environments**: Jupyter Notebook, VS Code, Git

---

## 📂 저장소 구조 및 주요 프로젝트

### 📊 1. 핵심 프로젝트 (`05_Project`)

데이터 전처리부터 모델링 및 비즈니스 인사이트 도출까지 아우르는 데이터 파이프라인 전 과정을 다룬 DA & AI 프로젝트입니다.

- **[01_Basic_Project](./05_Project/01_Basic_Project)**: 영화 평점 데이터를 활용한 기초 데이터 분석 프로젝트입니다. 데이터 전처리(`01_preprocessing_v1.ipynb` ~ `v10.ipynb`), 검증(`dong_verification.ipynb`) 및 기초 통계 모델링 과정을 포함하고 있습니다.

### 💼 2. 실무형 미니 프로젝트 (`01_Daily_Project`)

실제 비즈니스 문제와 기술적 과제를 시뮬레이션하기 위해 기획된 실습 중심의 집중 프로젝트입니다.

- **PJ08_금융 도메인 실무 프로젝트(예시)**: 금융 도메인 데이터 분석 및 시뮬레이션.
- **PJ09_ConfusionMatrixSimulator**: 분류 모델 성능 평가를 위한 실용적인 접근법 및 시뮬레이터 개발.
- **PJ07_통계검정_종합_의사결정트리**: 의사결정나무 모델로 이어지는 종합적인 통계 검정 프로젝트.
- **PJ05_Fintech_Data_Pipeline**: 핀테크 애플리케이션에 맞춤화된 데이터 파이프라인 개발.

### 📈 3. 데이터 분석 및 EDA 트레이닝 (`04_EDA_Traning`)

탐색적 데이터 분석(EDA), 통계적 기초 및 데이터 기반 인사이트 도출을 위한 체계적인 훈련과 실습 내용입니다.

- **2026_01 & 2026_02**: 실전 EDA 기법에 맞춘 월별 트레이닝 모듈.

### 🧠 4. AI 및 머신러닝 스터디 (`07_AI_Study`)

인공지능(AI)에 대한 심층 학습 공간입니다.

- **01_Vibe_Coding**: AI 모델에 대한 직관을 기르고 실험적인 코딩(Vibe Coding)을 진행하는 공간.

### 🧑‍💻 5. 코딩 및 기초 학습 기록

프로그래밍 역량을 유지하고 기초 지식을 탄탄히 하기 위한 꾸준한 학습 공간입니다.

- **[`02_Codekata`](./02_Codekata)**: 일일 파이썬 코딩 과제 (아카이빙 용).
- **[`03_Coding_Study`](./03_Coding_Study)**: 부트캠프 및 개인 학습 기록. 파이썬 세션, EDA, SQL, 통계학, 머신러닝의 기초 개념들을 다룸.
- **[`06_Python_Test`](./06_Python_Test)**: 파이썬 활용 능력 테스트 및 검증 결과.
