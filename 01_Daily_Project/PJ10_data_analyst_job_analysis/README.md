## 2. 🛠 기술 스택 및 AI 활용도

이 프로젝트의 **모든 파이썬 코드(크롤링, 전처리, 시각화)는 AI(Claude)가 작성**했으며, 저는 **프롬프트 엔지니어링과 결과물 기획 및 검증**에 집중했습니다.

### 발전된 기술 스택 (AI Auto-Generated)

- **Language:** Python 3.x
* **Data Processing:** `pandas`, `numpy`, `re` (정규표현식 파싱)
* **Visualization:** `matplotlib`, `seaborn`, `wordcloud`
* **NLP & Stat:** `collections.Counter`

### 🤖 AI 협업 워크플로우 (Human-AI Collaboration)

| 진행 단계 | Human (나의 역할: 프롬프트 엔지니어링 및 기획) | AI (Claude의 역할: 코드 구현 및 실행) |
| :--- | :--- | :--- |
| **추출 (Extract)** | "잡코리아 데이터분석 직무 공고 250개 크롤링해줘" | 스크레이퍼 코드 작성 및 데이터 수집 실행 |
| **정제 (Clean)** | "SI/SM 중복 공고 제거하고 순수 분석 직무만 필터링해줘" | 정규식 패턴 매칭 및 논리적 데이터 필터링 |
| **시각화 (Visual)** | "신입/경력 비율, 상위 요구 스택 시각화해줘" | Matplotlib/Seaborn 차트 코드 최적화 및 생성 |
| **해석 (Insight)** | "현재 시장에서 최우선으로 필요한 역량 요약해줘" | 교차 분석을 통한 통계 요약 및 채용 전략 도출 |

## 3. ⚙️ 데이터 분석 파이프라인 (Pipeline)

### Step 1: 데이터 수집 (Web Scraping)

* **대상:** 잡코리아 "데이터 분석" 검색 공고 **250건** 전수조사
* **수집 항목:** 공고명, 지원 자격(경력/학력), 주요 업무, 사용 기술 스택, 우대 사항(자격증/핵심 역량), 급여 등

### Step 2: 전처리 및 필터링 (Data Cleaning)

* 중복 공고 및 무관 직무(순수 백엔드 개발, 자바 SI/SM 등) 노이즈 제거
* 텍스트 마이닝을 통한 정규화 작업
* **최종 분석 대상:** 순도 높은 데이터 분석 직무 공고 **101건 타겟팅 (데이터 신뢰도 향상)**

### Step 3: 다각도 데이터 탐색 (EDA)

1. **경력 요건 & 지역별 트렌드:** 신입 vs 경력 비율 파이차트, 수도권 집중도 분석
2. **핵심 스택 추출:** 공고 내 기술 스택 키워드 빈도 추출 및 랭킹 (TOP 25)
3. **우대 조건 워드클라우드:** `WordCloud`를 활용한 텍스트 빈도 시각화
4. **역량 분석:** 기업에서 중요하게 생각하는 태도 및 소프트 스킬 빈도 분석

## 4. 💡 주요 분석 인사이트 (Key Insights)

데이터 채용 시장의 핵심 트렌드는 다음과 같습니다.

### 📌 기술적 역량 (Hard Skills)

1. **SQL (압도적 1위):** 데이터를 다루는 모든 직무의 필수 언어
2. **Python (2위):** 분석부터 시각화, 전처리까지 범용적인 필수 언어
3. **Excel & BI 도구:** 전통의 강자 Excel과 더불어 최근 급부상한 Tableau, Power BI 등 대시보드 역량 요구 증가
4. **우대 자격증:** 실무 능력을 방증하는 `SQLD` 및 `ADsP` 자격증 수요 다수 포진

### 🧠 정성적 역량 (Soft Skills)

* 기술력 못지않게 **성실성, 꼼꼼함, 협업 능력**이 공고에서 가장 많이 언급되는 핵심 역량으로 나타남.
* 단순한 툴(Tool) 사용법을 넘어, **주도적으로 문제를 정의하고 협업을 통해 비즈니스 가치로 연결하는 역량**을 강하게 요구함.

## 5. 🎓 회고 및 배운 점 (Retrospective)

### 🚀 "프롬프트가 곧 코딩이다"

* AI에게 모호한 지시보다는, **"결측치를 제거하고, A열과 B열을 크로스탭해서 파이차트로 그려줘. 색상은 파스텔톤으로 해줘"**처럼 **구체적이고 명확한 지시**가 높은 퀄리티의 산출물로 이어짐을 경험했습니다.

### 🔍 도메인 지식과 검증 능력의 필요성

* AI가 작성한 정규식이나 논리 구조가 100% 완벽하지 않을 때가 있었습니다 (예: 차트 한글 깨짐, 과도한 필터링 등).
* 결국 AI를 제대로 활용하기 위해서는 **데이터를 파악하는 안목과 기초적인 파이썬 트러블슈팅 지식**이 뒷받침되어야만 올바른 방향타를 잡을 수 있음을 체감했습니다.

### 💡 AI 시대, 분석가의 진짜 역할

* 데이터 전처리와 시각화 코딩에 소모되는 시간은 획기적으로 줄었습니다.
* 이제는 **"어떤 외부 데이터를 융합할 것인가?", "이 수치가 의미하는 비즈니스 인사이트는 무엇인가?"**를 고민하는 **인간 고유의 문제 정의 및 해석 능력**에 더 많은 시간과 에너지를 투자해야 할 때입니다.
