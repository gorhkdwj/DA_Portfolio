## 1. Project Overview

* **프로젝트 명:** PJ08_금융 도메인 실무 프로젝트 (예시)
* **수행 기간:** 202X.XX.XX (1일)

### 💼 가상 시나리오 (Scenario)
>
> **"대출 심사팀의 요청: 누가, 왜 대출을 잘 갚는가?"**
>
> 당신은 **A은행의 데이터 분석가**입니다. 대출 심사팀으로부터 **"어떤 고객 특성이 대출 상환 능력과 관련이 있는지 분석해 달라"**는 요청을 받았습니다.
>
> 목표는 가상의 고객 데이터(500건)를 바탕으로 데이터 탐색부터 가설 설정, 통계 검정까지의 일련의 과정을 수행하여 유의미한 비즈니스 인사이트를 도출하는 것입니다.

* **목표:**
  1. **AI 활용 경험:** AI가 제안하는 분석 코드와 로직을 검토하고 실행하며 학습.
  2. **통계 검정 흐름 파악:** 데이터 유형 파악 -> 가설 설정 -> 검정 -> 해석으로 이어지는 프로세스 체화.
  3. **비즈니스 인사이트 도출:** 수치적 결과(p-value 등)를 비즈니스 언어로 해석하는 능력 함양.

## 3. Implementation Details

프로젝트의 전체 흐름: **[데이터 생성 -> 탐색(EDA) -> 가설 검정 -> 결론 도출]**

### Step 1: 가상 데이터 생성 (Data Generation)

* 12개의 컬럼을 가진 500명의 가상 대출자 데이터를 생성합니다. (성별, 고용형태, 연소득, 신용점수, 대출금액 등)
* 현실성을 위해 결측치(NaN)를 일부 주입하고, 상관관계를 반영하여 종속변수(대출승인여부)를 생성했습니다.

### Step 2: 데이터 유형 분류 및 기술통계 (EDA)

* 변수들을 명목형, 순서형, 이산형, 연속형으로 분류하고 각 특성에 맞는 기술통계량을 확인합니다.
* 왜도(Skewness) 등을 통해 데이터 분포의 치우침을 파악합니다.

### Step 3: 통계적 가설 검정 (Statistical Hypothesis Testing)

* "신용점수가 높은 고객이 대출 승인 확률이 높을까?" 와 같은 가설을 설정합니다.
* t-test, ANOVA, Chi-square 등 통계적 기법을 사용하여 가설을 검증하고, **p-value**를 해석합니다.
