# PJ15_자영업 분석 자료 보충을 위한 성남시 뉴스 크롤링 분석

**(부제: 성남시 자영업·상권 관련 뉴스 크롤링)**

> **"PJ14의 한계를 넘어, 자영업 분석에 필요한 데이터를 직접 수집한다"**
> PJ14에서 문제 지시어 필터링으로 제외된 자영업·상권 관련 중립 기사를
> 목적 키워드 기반으로 재수집하여 PJ15 분석의 원천 데이터를 확보한다.

---

## 1. Project Overview

- **프로젝트명:** PJ15_자영업 분석 자료 보충을 위한 성남시 뉴스 크롤링 분석
- **수행 기간:** 2026.04.07 ~

### 프로젝트 배경

PJ14에서 19,472건의 성남시 뉴스를 수집하여 공공 문제 키워드를 분석하였으나,
팀 논의 과정에서 분석 목적이 **"자영업 분석용 데이터 수집"** 으로 변경되었다.

PJ14의 구조적 한계:
```
19,472건 전체
    ↓ 문제 지시어 필터 (민원, 논란, 갈등, 피해 등 부정 기사만 통과)
3,190건
    ↓ "상권 현황", "소상공인 매출" 등 중립 자영업 기사 대부분 제외됨
```

→ 자영업 분석에 필요한 중립/정보성 기사는 필터 단계에서 걸러지는 구조이므로
**목적 키워드로 별도 크롤링**하여 원천 데이터를 새로 확보하는 것이 필요하다.

### 목표

1. 성남시 자영업·상권 관련 뉴스 수집 (2023-01-01 ~ 2025-12-31, 3년치)
2. 수집 데이터 기반 자영업 현황 분석
3. 공공데이터와 연계하여 성남시 자영업 인사이트 도출

### 수집 기간

| 항목 | 내용 |
|---|---|
| 시작일 | 2023-01-01 |
| 종료일 | 2025-12-31 |
| 구간 수 | 1,095개 (1일 단위) |
| 예상 소요 시간 | 18~36시간 |

## 3. 크롤러 구조 (`naver_news_crawler.py`)

PJ14 크롤러를 기반으로 하며, 체크포인트 기능이 추가되었다.

### 3-1. 수집 설정

```python
# 수집 전체 기간 (2023-01-01 ~ 2025-12-31)
CRAWL_START = datetime(2023, 1, 1)
CRAWL_END   = datetime(2026, 1, 1)  # 2025-12-31 포함을 위해 하루 뒤로 설정
```

> **키워드 설정 필요:** `__main__`의 `keyword` 인자를 분석 목적에 맞게 변경 후 실행.
> 예시: `"소상공인 성남"`, `"자영업 성남"`, `"성남 상권"`

### 3-2. 함수 구조

```
generate_segments(interval_days=1)  ← 1일 단위 1,095구간 생성
crawl_segment()                     ← 단일 구간 수집
append_to_csv(write_header)         ← append 모드 즉시 저장
run_full_crawl()                    ← 체크포인트 기반 순차 실행
```

### 3-3. 체크포인트 기능 (PJ14 대비 추가)

PJ14에는 없었던 중단 후 재시작 기능을 추가하였다.

| 상황 | 동작 |
|---|---|
| 최초 실행 | `{keyword}_checkpoint.json` 생성, CSV 신규 생성 |
| 구간 완료 시마다 | 완료 인덱스 + 누적 건수 + CSV 경로 체크포인트 저장 |
| 중단 후 재실행 | 체크포인트 읽어 완료 구간 건너뜀, 기존 CSV에서 `seen_links` 복원 |
| 전체 완료 시 | 체크포인트 파일 자동 삭제 |

## 4. PJ14와의 차이점

| 항목 | PJ14 | PJ15 |
|---|---|---|
| 수집 기간 | 2024-04 ~ 2026-04 (2년) | 2023-01 ~ 2025-12 (3년) |
| 키워드 | 성남시 (시정 전반) | 자영업/상권/소상공인 (목적 특화) |

| 목적 | 공공 문제 키워드 발굴 | 자영업 분석 원천 데이터 확보 |
