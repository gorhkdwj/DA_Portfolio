잔차(Residual) · RSS · OLS

직선을 직접 움직이면서 잔차가 뭔지, RSS가 왜 줄어드는지 체감하세요

💡 개념 흐름
잔차(e) = 실제값(y) − 예측값(ŷ)  ← 각 점마다 존재
RSS = Σ e²  ← 잔차를 제곱해 모두 더함
OLS = RSS가 최소가 되는 β₀, β₁ 조합
왜 제곱하나?
① 잔차에는 +와 −가 섞여 있어서 그냥 더하면 상쇄됨 → 제곱하면 모두 양수
② 작은 오차는 작게, 큰 오차는 훨씬 크게 벌점 → 직관적으로 "나쁜 직선"에 큰 패널티
③ 제곱 함수는 매끄럽게 미분 가능 → 수학적으로 최솟값 계산이 쉬움

손실함수 비교: MSE vs MAE vs Huber

이상치(Outlier)를 추가해서 세 손실함수가 얼마나 다르게 반응하는지 직접 보세요

💡 핵심 차이점
손실함수오차 작을 때오차 클 때이상치 민감도미분 가능?
MSEe²e² → 폭발매우 민감 ⚠️✓ 전체
MAE|e||e| → 선형강인 ✓✗ 0에서 불가
Hubere² (MSE처럼)|e| (MAE처럼)절충 균형✓ 전체
MSE가 회귀의 기본 손실함수인 이유:
① 모든 점에서 미분 가능 → 경사하강법이 안정적
② 볼록(Convex) 함수 → 최솟값이 반드시 1개
③ 오차가 정규분포라는 통계 가정과 수학적으로 동일 (MLE = OLS)
🎮 이상치를 추가/제거해보세요
이상치 0개 — 세 손실함수 값이 비슷합니다.
각 방법으로 맞춘 회귀선 비교:
이상치가 생기면 MSE 직선이 크게 당겨지고, MAE 직선은 거의 변하지 않으며, Huber 직선은 중간 정도 반응합니다.
이상치가 많거나 데이터가 노이즈할수록 MAE·Huber가 유리합니다.
📐 손실함수 모양 비교 (오차 크기별 벌점)
오차가 ±3 이상일 때 MSE(파랑)는 급격히 치솟지만 MAE(빨강)·Huber(초록)는 완만합니다.
이 차이가 이상치 민감도의 원인입니다.

다중공선성(Multicollinearity) · VIF

변수들 사이 상관이 높아지면 회귀계수(β)가 어떻게 불안정해지는지 확인하세요

💡 핵심 개념
다중공선성이란? 독립변수들끼리 서로 높은 상관관계를 가질 때 발생하는 문제입니다.

예: TV광고비와 라디오광고비가 거의 같은 패턴으로 움직인다면,
"매출 증가가 TV 때문인가, 라디오 때문인가?"를 구분할 수 없음 → β 값이 불안정하게 흔들림

VIF(분산팽창지수) = 다중공선성의 심각도를 수치로 나타낸 지표
VIF 값해석조치
< 5양호 ✓그대로 사용
5 ~ 10주의 필요상황 모니터링
> 10심각한 다중공선성 ⚠️변수 제거 or Ridge 적용
🎮 변수 간 상관관계를 조절해보세요
0.10
VIF 측정값
상관계수가 높아질수록 β값이 크게 흔들립니다.
왜 β가 흔들리나?
X₁과 X₂가 비슷한 정보를 담으면, 모델은 β₁=10, β₂=0 으로 해도, β₁=0, β₂=10 으로 해도 예측이 비슷합니다. 즉, 정답이 무수히 많아져서 데이터가 조금만 바뀌어도 β가 크게 달라집니다.

해결책: Ridge(L2 규제) → β² 에 벌점을 줘서 β값이 극단적으로 커지지 못하게 잡아줌

🎮 시나리오를 선택하세요

⚠️ 이상치 있음

R²는 괜찮지만 RMSE ≫ MAE → 큰 오차 몇 개 존재

📉 과적합

Train R² 높고 Test R² 낮음 → 새 데이터 일반화 실패
